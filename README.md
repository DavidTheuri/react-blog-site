# React Blog Site

This project is a simple personal blog website built with React. The application was created to practice working with components, JSX, and props in React.

## Features

- Header component
- About section
- Article list
- Article components
- Dynamic rendering using props

## Technologies Used

- React
- JavaScript
- Vite
- CSS
